# TypeScript Practical Answers

This folder contains solutions to the TypeScript practical exercises.
The solutions are grouped by category and correspond to the questions in the `Practical/` folder.

---

## Fix-the-Code
These exercises focus on **correcting type errors or missing type annotations** so the code compiles properly.

---

## Debugging
These exercises focus on **debugging TypeScript code** that may have type mismatches, incorrect logic, or unsafe assumptions.

---

> Questions are located in the `Practical/` folder.
