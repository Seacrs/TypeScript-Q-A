# TypeScript Practical Questions

This folder contains question on TypeScript
The questions are grouped by category

---

## Fix-the-Code

These exercises focus on **correcting type errors or missing type annotations** so the code compiles properly.

---

## Debugging
These exercises focus on **debugging TypeScript code** that may have type mismatches, incorrect logic, or unsafe assumptions.
